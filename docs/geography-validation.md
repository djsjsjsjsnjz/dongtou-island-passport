# 真实地理骨架验收（2026-09-23）

**结论：地形、建筑分布、道路贴地与最小玩家闭环已实现并运行；完整地理验收未通过。不能进入玩法阶段。**

这份记录替代本轮之前的零 DEM/1 建筑性能与验收结论。上一版记录留作历史，不应再作为当前地图能力证明。

## 空间与数据

WGS84 原点 `[121.157,27.8255]`；bbox `[121.14685,27.81648,121.16715,27.83452]`；约 1999.95×1999.13m。世界坐标米制 +X 东、-Z 北、+Y 上。所有 OSM 点保留原始经纬度。公开建筑按原文件 WGS84 UTM 49N 正式重投影。没有使用整体图层平移。

- DSM：真实 Copernicus GLO-30，77×69 样本，0–114.238m；固定 1×。200×200 规则网格按真实岸线裁剪，61,992 个地形三角面；10m 网格不是 10m 测量精度。
- 建筑：最终 2,789 栋（1 OSM +2,788 EAB）。原 EAB 范围内 2,789 栋，1 个重叠候选优先采用 OSM。每栋可追溯 DOI/原始记录。检查未发现陆地外面积超过 5% 的轮廓；仍不能证明 ML 漏检、误检或时效问题不存在。
- 道路：49 个 OSM 要素，6,829 个加密中心线片段；原平面拓扑不变。桥梁、隧道、步道/普通道路的政策分离，steps 类型有测试但本快照未含实际 steps。
- POI：11 个原始 WGS84 代表点。出生点/玩家到达点另存，不替换原 POI，不称作真实入口。

## 未解决的地理冲突

1. `way/1484029116` 有 4 个加密片段与 OSM 内陆水面相交，未标为 bridge。保留原始道路平面位置，QA 红色高亮，玩家阻挡水体。需要权威数据判断是涵洞/桥、道路/水面边界偏差还是标注遗漏；本轮没有凭空加桥。
2. 半屏大桥 `way/506084787` 保留真实平面路线，暂定桥面由两端 DSM 高程线性连接，最低约 22.2m，未被压到海面。缺少桥面/净空实测，不能宣称真实纵断面已建立。
3. 隧道 `way/702532882` 不显示为山体表面道路，也不允许进入。缺少洞口及地下纵断面；QA 只显示平面线位。
4. 四个 Sentinel 粗参考点到最近 OSM 岸线距离约 20.06、2.07、35.91、39.78m；后两个超过约 20m 判读不确定度。对应点选择、潮位、OSM 高潮岸线语义可能影响结果，但没有证据可消除冲突。**这些不是精确同名点 RMSE**，也不能用来平移岸线。
5. 没有本轮授权高德 POI 或带凭证的 GCJ-02→WGS84 成果。所有高德比较字段为 null，真实入口也为 null。未调用非授权逆向公式，未将 GCJ-02 与 WGS84 混用。
6. 建筑虽有明确开放许可与逐栋追溯，仍缺高分辨率正射/测绘验证、最新覆盖及真实高度。DSM 同样有树冠/建筑影响，不能当作裸地测绘。
